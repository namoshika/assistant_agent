# ADR-007: mlflow の複数コンテンツ対応制限に対する暫定対処

- **日付**: 2026-03-11
- **ステータス**: 採択（暫定）

## 背景

現在使用中のバージョンの mlflow が、LLM から返却される「複数種類のコンテンツ（テキスト、画像、ツール呼び出しなど）から成るレスポンス配列」を適切に処理できないという制約がある。
このため、LangGraph を通じて得られたレスポンスをそのまま mlflow に渡すと処理の過程でエラーが発生してしまう。

## 決定

- `src/agent_assistant/utils/mlflow.py` の `LangGraphWrapper` において、レスポンスの `content_blocks` 配列の中から `type == "text"` の要素のみを抽出し、単一の文字列に連結して扱う処理（ワークアラウンド）を追加した。

## 影響・備考

- 本対応は mlflow のバージョン制約に起因する暫定的な措置である。
- mlflow の将来のバージョンアップで複数コンテンツのストリーミングやロギングがネイティブにサポートされた段階で、このワークアラウンドを取り除くよう再検討する。
