# ADR-006: 開発環境のコンテナ化（Devcontainerの導入）

- **日付**: 2026-03-11
- **ステータス**: 採択

## 背景

ノートブックのセル上で mlflow をインポートした際にカーネルが異常終了する問題が発生していた。コンテナ上では不具合が発生せず、WSL 環境では発生する。対策として開発環境をコンテナ化することとした。

## 決定

- VSCode Devcontainer を導入し、`.devcontainer/` ディレクトリ配下に `devcontainer.json` を配置した。
- コンテナ起動時のフックとして `hook_post_create.sh` や `init_env.sh` を定義し、パッケージのインストールなどを自動化するようにした。

## 影響・備考

- 今後の開発は Devcontainer を立ち上げて行うことが標準となる。
- 新規参画時などの環境構築の手間が大幅に削減される。
